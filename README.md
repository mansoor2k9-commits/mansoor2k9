**Description:** Built an interactive Power BI dashboard utilizing historical shift logs and payroll records. The project involved data cleaning in Python/Pandas, SQL data modeling, and designing visual reports tracking labor utilization, overtime hotspots, and department-level throughput.

**Skills:** Data cleaning, workflow optimization, exploratory data analysis (EDA), interactive dashboarding, KPI tracking.

**Technology:** Power BI, SQL, Python, Pandas, Excel (Advanced).
